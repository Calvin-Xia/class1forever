# 完整字体生成输入

这里保留分片前的完整 WOFF2 字节和原始清单，供可复现生成与 cmap/可变字形核验。
它们不在 `public/`，不会发布到两平台静态资产。

来源固定为 Google Fonts 提交 `e9678a5385322c63730122ba464765baad83cfd8`，完整来源、原始 TTF SHA-256、压缩后 SHA-256 见 `manifest.json`。
SIL OFL 版权及许可证保存在 `../public/fonts/*-OFL.txt`，构建仍发布许可证。

生成/核验方法见 `../docs/font-subsets.md`。不读取任何学生名单。
